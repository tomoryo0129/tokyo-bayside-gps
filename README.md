# 東京ベイサイドゴルフ GPSナビ（GitHub Pages / PWA版）

## 含まれる機能
- OUTコース9ホール・INコース9ホール（全18ホール）のグリーン手前・中央・奥の座標
- GPS現在地取得、GPS追跡、ヤード距離表示
- ショット地点記録、打つ前の0/1/2打罰記録
- グリーン／カラー到達の記録
- ホールごとのショット数・パット数保存
- ラウンド記録JSONエクスポート、スコア全クリア、ショットGPSを含む完全初期化
- ラウンド後の航空写真でショット軌跡確認
- PWAマニフェスト、ホーム画面アイコン、Service Worker

## GitHub Pagesへの登録
1. 新しいPublicリポジトリ（例: `tokyo-bayside-gps`）を作成します。
2. ZIPを解凍し、中身の `index.html`、`manifest.webmanifest`、`sw.js`、`icons` をリポジトリのrootにアップロードします。ZIP自体を置くだけでは動きません。
3. Settings → Pages → Deploy from a branch → `main` / `/(root)` → Save。
4. 公開URL（通常 `https://ユーザー名.github.io/tokyo-bayside-gps/`）をSafariで開き、位置情報を許可します。
5. Safariの共有ボタン → ホーム画面に追加。

## 更新・データについて
- 本アプリは東京ベイサイド版専用の保存キー（`tokyoBaysideGolf...`）を使用し、マナゴルフ版・江戸川版の記録とは分離します。
- 座標はユーザー提供値です。PAR情報は未提供のため設定していません。距離は登録地点までの直線距離で、GPS誤差・高低差等により実距離とは異なります。
- GPS追跡はアプリを前面表示して利用してください。iOSはバックグラウンドでの連続取得を保証しません。
- ラウンド記録は端末のブラウザ内に保存されます。定期的にJSONでバックアップしてください。
